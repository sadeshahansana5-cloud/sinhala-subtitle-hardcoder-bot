<a id="about"></a>
<p align="center"><img src="https://capsule-render.vercel.app/api?type=waving&color=0:134E5E,100:71B280&height=110&section=header&text=About&fontSize=36&fontColor=fff&fontAlignY=45" width="100%" alt="About"></p>

**Sub Analyser Bot** turns a video and an `.srt` file into a video with **perfectly shaped Sinhala subtitles**, right inside Telegram. It fixes the subtitle file, lets you test the timing, encodes with the quality mode you pick, checks the result, and sends it back with a preview image.

| 🎯 Made for | 💡 Why it is nice |
|---|---|
| 🎬 Subtitle teams and channels | One tap **hardcode** or **embed**, no desktop software |
| 🧑‍🎓 Casual users | Free trial, simple buttons, clean English messages |
| 👑 Bot owners | Credits, premium limits, admin cards, backups |
| ☁️ Free hosting users | Built for Hugging Face Spaces, restart safe |

<a id="quick-start"></a>
<p align="center"><img src="https://capsule-render.vercel.app/api?type=waving&color=0:11998e,100:38ef7d&height=110&section=header&text=Quick%20Start&fontSize=36&fontColor=fff&fontAlignY=45" width="100%" alt="Quick Start"></p>

```text
  📥 Send video  ──►  📄 Send .srt  ──►  ⏱ Test timing  ──►  🎛 Pick a mode  ──►  🔥 Hardcode / 🧩 Embed  ──►  📤 Get result
```

| Step | What you do | What the bot does |
|:---:|---|---|
| 1️⃣ | Send the **video** or a document | Downloads it with parallel streams and reads its details |
| 2️⃣ | Send the **`.srt`** file | Fixes numbering, removes empty lines, checks the intro gap |
| 3️⃣ | Optional: **Fix Delay** or **Demo clip** | Finds the shift automatically and renders a short test |
| 4️⃣ | Tap **🔥 Hardcode** or **🧩 Embed** | Asks for the time range and the quality mode |
| 5️⃣ | Choose the **watermark** option and the **tracks** to keep | Encodes and shows live progress with speed and time left |
| 6️⃣ | Rename the file if you want | Verifies the output and sends it with a preview image |

| 🧪 | **High Quality** | Maximum detail (the file can be large) |
| ♾ | **Lossless** | Largest file and the longest time |

### 🛡 Output verification
After every encode the bot checks the result before sending it:

- ✅ the file is **complete and playable**
- ✅ the **subtitle text is detected** in sample frames
- ✅ **SSIM and PSNR** are measured on a subtitle-free area
- ✅ the resolution matches what was planned

### ⚡ Turbo profile (optional)
Set `SPEED_PROFILE = "turbo"` in `config.py` for a much faster hardcode. Faster presets are paired with a lower CRF so the picture looks the same. The file is a little bigger. Test it on your own videos before you make it the default.

<p align="center"><img src="https://capsule-render.vercel.app/api?type=waving&color=0:4B1248,100:F0C27B&height=110&section=header&text=Stickers%20and%20Reactions&fontSize=36&fontColor=fff&fontAlignY=45" width="100%" alt="Stickers and Reactions"></p>

### 🧩 Sticker setup
1. Send `/stickers` and tap **🎯 Set stickers**.
2. The bot asks for one sticker per step: **Start, Menu, Download, Encode, Quality, Extract, Upload, Sync, Success, Error**.
3. Send the sticker, or tap **⏭ Skip** if a step does not need one.
4. Open **⚙️ Settings** to turn any step ON / OFF and to choose its own delete time.

| Step type | When the sticker disappears |
|---|---|
| 🏠 Start · 📂 Menu · ✅ Success · ❌ Error | After its own timer (3s, 5s, 10s, 30s or keep) |
| 📥 Download · 🎬 Encode · 🛡 Quality · 📤 Upload · 🎧 Extract · 🔄 Sync | When that step finishes |

⏳ **Order on screen:** a temp message appears first, then your sticker arrives, then the real message follows.

### 😎 Reactions
Every command, text, video and file you send gets a random emoji reaction so you know the bot got it. Turn it off with `REACT_ON_MESSAGES = "0"` in `config.py`.

### 💾 Restart safe
Stickers are saved in `sticker_store.json`, backed up in a pinned message, and a copy ships with the code as `default_stickers.json`. To refresh that copy, press **📦 Backup** and replace the file.

```python
    "STICKER_TTL_WELCOME": "6",
```


### 🔤 Before you start
- Put **your font** (`.ttf` or `.otf`) inside the `fonts/` folder. The first font in that folder is the default.
- Make sure **FFmpeg** and **fontconfig** are installed on the machine.

### ☁️ Hugging Face Space (Docker)
1. Create a new **Docker** Space and upload every file of this project.
2. Open **Settings → Secrets** and add:

| Name | Value |
|---|---|
| `API_ID` | from my.telegram.org |
| `API_HASH` | from my.telegram.org |
| `BOT_TOKEN` | from @BotFather |
| `ADMIN_IDS` | your Telegram user ID |

3. The Space listens on port **7860** (already the default).
4. 💾 Want users and stickers to survive restarts without any backup step? Turn on **persistent storage**; the bot saves into `/data` automatically.

### 🖥 VPS or local

```bash
git clone YOUR_LINK_HERE
cd Sub-Analyser-Bot
pip install -r requirements.txt
python main.py
```

<details>
<summary>🩺 <b>Troubleshooting</b></summary>

| Problem | What to do |
|---|---|
| 🧩 A sticker does not appear | Run `/stickers` again for that step. Sticker IDs belong to your bot token. |
| 🐢 Downloads or uploads are slow | Check that `TgCrypto` installed correctly in your logs. |
| 🔤 Log says "No font found" | Put your `.ttf` or `.otf` file in the `fonts/` folder. |
| 🔐 Everyone is unlimited | Set `ADMIN_IDS`. Access control stays off without an admin. |
| 😎 Reactions do not show | Check the logs for "Reaction ... failed" and share that line. |
| 💾 Data disappears after a restart | Turn on persistent storage, or press **📦 Backup** in `/stickers`. |
| 🌐 Mini App is missing | Send `/webapp on` and make sure `PUBLIC_URL` is an HTTPS address. |

</details>

<details>
<summary>❓ <b>Frequently asked questions</b></summary>

**Does the bot change my video quality?**
The quality mode you pick decides the encode settings. The bot then verifies the output and shows the result.

**Can a normal user process unlimited videos?**
No. A new user gets the free trial. After that the admin must approve the user and give credits.

**What happens to my video on the server?**
It is kept for a limited time and then removed. You can delete it any time with `/delete`.

**Can I use my own Sinhala font?**
Yes. Upload a `.ttf` or `.otf` with `/fonts`. Fonts are private to each user.

**Can I change every message and timer?**
Most timers, limits and switches live in `config.py`. Sticker timers can also be changed inside `/stickers`.

</details>
